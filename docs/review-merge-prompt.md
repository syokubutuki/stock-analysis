### 1. まず状態を把握する


**`git merge-base main feat/series-unit-cleanup` が main の HEAD と一致するか確認すること。**

**② FU52 — (a) `%` を外して円にしたか、(b) 比率に直したか。そしてどの経路に残っているか**

  落ちたテストを緩めていないか、「実装とテストのどちらが正しいか」を報告してから変えたかを見ること

  **可視だけ直して代替に `%` が残る**のが S22 / S23 で繰り返し見た失敗の形である

**③ FU56 — 番兵の性質が保たれているか・他に NUL のファイルが無いか**
