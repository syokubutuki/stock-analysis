# 上昇後の初回下落までの日数分布

## 原系列上の期間表示

「1事例ずつ表示」と「全事例を表示」を切り替える。全事例モードは採用事例の全区間を
原系列に重ね、条件成立日を青いマーカー、成立済みの結果日を紫のマーカーで示す。
同日の結果マーカーは1点にまとめ、過密な積み重ねを避ける。表示事例は間引かない。
区間の重なりは色が濃くなるが、その濃さを件数や確率の尺度としては扱わない。
青の起点付近のクリック・事例一覧の日付から個別表示へ切り替える。
重複除外がオンなら採用後の全件であり、条件一致の全営業日を見たい場合は除外をオフにする。
全事例モードもlightweight-chartsで時間軸をズーム・パンでき、帯は描画フレームで座標に同期する。

採用事例を1件選び、選択した分析期間の終値をlightweight-chartsで表示する。
青の①→②は過去L営業日、②は条件成立日（0日）、橙の②→④は追跡区間。
紫の③は選択した下落条件の成立日または最高終値日。早く成立しても④はH日目のまま。
H日目まで価格がなければ④は観測末尾とし、未観測日数を併記する。未来の日付は生成しない。
最高終値日はH日目まで観測してから確定する旨を表示する。

事例の選択、前後の事例ボタン、事例一覧の日付ボタンから表示を変更できる。
既定は完全なH日窓を持つ最新事例、なければ最新事例。選択は分布の母集団を変えない。
ズーム・パン・リサイズに期間の帯を同期し、分析期間全体と事例区間の表示を切り替える。
計算層が返すlookbackStartIndex / signalIndex / followupEndIndex / availableFollowupを用い、
UIで日付から営業日を推測したり、結果の日から追跡上限を復元したりしない。

## 追加した定義（切り替え式）

既定の前日比マイナスに加え、前日比X%以上下落、K営業日連続下落、
起点を含む走行最高終値からX%以上下落、起点終値割れ、翌日〜H日後の最高終値日を選べる。
Xは0<X<100、Kは1〜Hの整数。必要なパラメーターだけ表示・検証する。
連続下落は同値・上昇でリセットし、K日目を成立日とする。起点以前の下落は数えない。
下落率の境界は浮動小数点の許容差を設け、閾値と同じ下落も含む。

最高終値日はJ=min argmax(翌日〜H日後の終値)。同値は最初の日を採用し、起点は除く。
完全なH日窓だけでF(k)=件数(J≤k)/完全窓数を計算する（経験分布）。
H日未観測の事例は一覧に残し、分布・分位・割合から除外する。KMの打ち切りにはしない。
完全窓がなければ推定不可と表示。最高終値がH日目の件数を別掲する。
H日が終わるまで確定せず、天井をリアルタイムで発見する機能でも、その後の反落を保証するものでもない。
以下の打ち切り・KMの仕様は下落条件の5モードに適用する。

- パネル: `cond-rise-to-decline`（今の条件から先を読む）
- 入力: 選択した分析期間内の修復済み日足。終値のみで成立し、投信にも対応。
- 計算: `app/lib/rise-to-decline.ts`
- UI: `app/components/analysis/RiseToDeclineChart.tsx`

## 定義

判定期間L、上昇率下限R%、追跡上限Hを独立に設定する。既定はL=5、R=5、H=20。
100(C[t]/C[t−L]−1) ≥ R の日tが条件成立日。入力の1バーを1営業日と数える。
判定日に下落していても、過去L日リターンが条件を満たせば対象になる。
初回下落は、k≥1で初めて C[t+k] < C[t+k−1] となる日。終値が同じ日は下落ではない。
起点価格割れ、日中高値からの反落、持続的な下降トレンドとは異なる。

既定では古い順に事例を採用し、その後H日間の条件成立は除く。
次の採用可能日はt+H+1。下落の実現日によって間引き間隔を変えない。
重複除外オフでは、条件に該当する全日を採用する。
除外オンでも判定期間の共有や相場局面の依存は残り、独立標本にはならない。

## 右打ち切りと推定

追跡可能日数A=min(H, 最終バーの添字−t)。観測時間Y=min(T,A)、発生フラグδ=1{T≤A}。
下落しなかった場合はY=A、δ=0であり、A日目の下落にも0日目の下落にも置き換えない。
H日目に下落した場合は発生。H日目まで未下落は上限による打ち切り、A<Hなら末尾による打ち切り。
翌日を未観測のA=0も一覧と件数には残すが、k≥1のリスク集合には含めない。

n[k]=Σ1{Y≥k}, d[k]=Σ1{Y=k,δ=1} とし、S[0]=1、S[k]=S[k−1](1−d[k]/n[k])。
同日発生と同日打ち切りはともにn[k]に含め、日末に取り除く。累積下落確率F[k]=1−S[k]。
中央値・四分位日はFが0.5・0.25・0.75に初めて達する日。
未到達の分位はnull。リスク集合がなくなった先のFは外挿せずnull（S=0ならF=1を維持）。
打ち切りと待ち時間の独立性や分布の安定性が成立しない場合は推定に偏りが生じうる。
独立標本を仮定した有意差・信頼区間や、未観測の裾を無視した平均待ち時間は表示しない。

ヒストグラムは発生を観測した件数だけを、幅ceil(H/20)の最大20ビンで示す。
これはカレンダー上の時系列ではなく待ち時間の度数分布。全日の日別表を併設する。
上限まで未下落・末尾打ち切りの件数を別掲し、分母の違いを説明する。

## データ品質・確認

取得は既存の `/api/stock` と状態管理を使用し、新しい取得や価格修復は行わない。
`StockData.dataQuality` とページ共通の `DataQualityNotice` は既存の経路を維持する。
不正な終値・日付順は分析エラーとし、欠損の除外による日数の圧縮や独自修復は行わない。

固定合成系列の回帰テストで、閾値一致、同値、終端、同日の発生と打ち切り、
追跡0日、固定間隔の重複除外、当日下落を数えないことを確認する。
