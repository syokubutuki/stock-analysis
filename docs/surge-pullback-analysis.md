# 急騰後の押し目と2週間の波の位置

入口は「今の条件から先を読む」→「急騰後の押し目と2週間の波の位置」。共有URLは `?panel=cond-surge-pullback`。ページ上部で選択した期間の日足を使う。

## 目的と初期値

前日比N%以上の日を起点に、下落幅D%へ初めて到達するまでの営業日数と、直近W営業日の高安位置を一緒に確認する。初期値はN=3%、D=2%、続伸U=3%、W=10、追跡H=10営業日。到達は終値で判定し、起点当日は数えない。

下落基準は起点終値、起点以降その日までの最高終値、前日終値から選択。最高終値基準は起点価格を上回る水準でも成立しうる。続伸は常に起点終値を基準にする。

## 表示と母集団

- 波の表示は、終値とローリング高安、高安からの経過日数、レンジ内位置の3種類。高安は当日を含むW本。高安の同値は直近日を採用。幅ゼロの位置は未定義。
- 真の高安更新は、当日の高安と直前のW本の高安との厳密比較。古い極値が窓から外れた変化を別表示する。最初のW本は起点に採用しない。
- 位置のフィルターは起点時点で80以上、20以下、すべて。高値更新日のみにも絞れる。
- 下落到達の累積確率は既存の `survival.ts` のKaplan–Meier。未到達・末尾打ち切り・0日観測を件数として残す。中央値は累積確率が50%へ達する最初の日。追跡対象が尽きた先は外挿しない。
- 経路の25/50/75%点と先着比較は全H日観測できた同じ事例群で計算し、完全観測件数を表示。途中事例を成功だけ取り込まない。個別経路は途中事例も観測分だけ表示。
- 通常日は前日比N%未満（大幅下落日も含む）かつ同じ位置・高値更新条件。比較群と急騰群を独立に間引くため、二群の追跡区間が重なる場合がある。通常日は因果推論の対照群ではない。
- 重複除外は採用起点tの次をt+H+1以降に固定。早期に下落しても次の採用を早めない。
- 下落前の最大上昇率は起点0%と下落前日の終値までの最大。未到達ならH日目まで。完全観測例の中央値を表示する。

## データと実装

計算は `app/lib/surge-pullback.ts`、UIは `SurgePullbackChart.tsx`。登録は `panel-registry.tsx` の1レコードでSSR無効の動的読み込み。既存の `/api/stock` → `useAnalysisData` を使い、取得・修復・SANITIZER_VERSIONは変更しない。修復開示は全ページ共通の `DataQualityNotice` を継続利用する。高安が必要なので終値のみの系列では非表示。

時系列はすべて `lightweight-charts` v5。相対日数も同ライブラリを使用し、内部時刻を0日目からの営業日表示へ変換。自動リサイズとアンマウント時のremoveでチャートを後始末する。

## 限界

これは履歴の記述分析で、売買成績や未来の確率を保証するものではない。引け後に条件確定するため、その終値での約定を仮定しない。コスト・滑り・翌日の寄付きは評価しない。分位点は値動きの分布で信頼区間ではない。標本の依存、相場変化、打ち切りと時期の関係、条件探索による過剰適合に注意。条件を固定して将来の未使用期間で別途検証する。

固定合成系列の黄金値テストで、下落定義、KMと打ち切り、分位点、先着、窓落ち、同値、先読み排除、重複除外、異常入力を確認する。
