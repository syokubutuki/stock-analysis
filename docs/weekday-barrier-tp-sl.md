# 曜日ビン別 TP/SL ─ バリア設計の何が測れて何が測れないかの設計書

対象: 「曜日（あるいは前夜米国ビン）ごとに最適な利確幅・損切り幅があるはずだ」という仮説。
保有期間は**日中（寄→引）から数週間**までを射程に置く。

新規: `app/lib/weekday-barrier.ts` / `app/lib/weekday-barrier.worker.ts` /
`app/components/analysis/WeekdayBarrierChart.tsx` / calendar 節の `cal-weekday-barrier` /
原論の**系C28**（C27 はセクター内選別が予約済み）。

---

## 0. 一言結論（これを画面の最上段に出す）

```
σ単位のバリア（TP=+Aσ√H / SL=−Bσ√H）は、暦時間あたりのシャープレシオを
一切変えない。変えられるのは勝率・歪度・回転率・期待滞在時間だけである。

  期待損益 = μ × 期待滞在時間 = μ · AB · H     （バリアは滞在時間しか動かさない）
  暦時間シャープ = μ√T/σ                       （A, B に依存しない）

したがって「期待値を最大化する TP/SL」の探索は、理想モデル下では
  μ>0 → AB→∞（＝バリアを外して持ち切り）／μ<0 → 建てない
という自明解にしか収束しない。格子探索が内点に最適解を返したなら、
それは (a) 経路依存性の証拠か (b) 推定ノイズのどちらかであり、
両者を切り分けることが本コンポーネントの唯一の仕事である。
```

曜日を切る意味があるのは (a) の経路依存性に曜日差があるときのみ。
σ差は正規化で消え、μ差は系C26 により識別不能だからである。

## 1. 理論 ─ 5つの閉形式（実装はこの5式に還元される）

対数価格を算術ブラウン運動 `X_t = μt + σW_t`（`X_0 = 0`）とし、上バリア `a = Aσ√H`（TP）、
下バリア `b = Bσ√H`（SL）、時間切り `H`。`A, B` は**ボラ単位のバリア幅**。

### 1.1 到達確率 ─ ν = 2μ/σ² の martingale から厳密解

`h(x) = e^{−νx}`（`ν = 2μ/σ²`）は生成作用素 `L = μ∂ + (σ²/2)∂²` の調和関数（`Lh = 0`）。
`h(X_t)` は martingale なので `E[h(X_τ)] = h(0) = 1`。よって

```
p ≡ P(TP に先に到達) = (1 − e^{νb}) / (e^{−νa} − e^{νb})

  νa = 2A·S,  νb = 2B·S      ただし  S = μ√H / σ  （その期間のシャープ）
```

> **この式が本設計の中心。** σ単位でバリアを切ると、到達確率は `(A, B, S)` だけの関数になり、
> **σ が完全に消える**。曜日別に「最適な %幅」が違って見えても、それは σ_dow の違いを
> 再発見しているだけであり、`(A, B)` の最適点に曜日差が残るのは `S_dow`（＝μ_dow）に差があるときだけ。
> **曜日別 TP/SL の最適化問題は、σ正規化した瞬間に「曜日別シャープ S_dow の推定問題」と厳密に同一になる。**
> そして `S_dow` の推定精度は系C26 で決まっている（§2）。

### 1.2 μ=0 の極限 ─ 期待値はゼロ、動くのは形だけ

`μ → 0` で `p → B/(A+B)`。実現損益は `+A`（確率 `B/(A+B)`）か `−B`（確率 `A/(A+B)`）で（σ√H 単位）、

```
勝率      = B/(A+B)
期待値    = A·B/(A+B) − B·A/(A+B) = 0        ← 任意停止定理
標準偏差  = √(AB) · σ√H
歪度      = (A − B)/√(AB)
期待滞在  = E[τ] = ab/σ² = AB · H
```

**μ=0 なら、どんな TP/SL も期待値を動かさない。** 動くのは勝率・歪度・保有時間の3つで、
しかもこれらは `(A, B)` の閉形式であり**推定を一切必要としない**。
「勝率を上げたい」なら `B > A`（浅い利確・深い損切り）、「歪度を正にしたい」なら `A > B`。
これは好みの設定であって発見ではない。

### 1.3 期待損益は滞在時間経由でしか動かない

`X_t − μt` が martingale なので Wald の等式より `E[X_τ] = μ·E[τ]`。§1.1 を小 `S` で展開すると

```
p ≈ B/(A+B) + AB·S/(A+B)
E[X_τ] ≈ AB·S·σ√H = μ · AB · H = μ · E[τ]      （§1.2 の E[τ] と厳密に整合）
```

> **バリアは「μ の増幅器」ではなく「期待滞在時間を AB·H に設定する装置」にすぎない。**
> 期待損益は `μ ×（建玉が市場に晒されていた時間）`。単位時間あたりに直すと
> `E[X_τ]/E[τ] = μ` で `A, B` に依存しない。

### 1.4 暦時間シャープはバリアに不変（コストゼロ・iid の下で）

暦期間 `T` に `n = T/(AB·H)` 回トレードすると

```
総期待値 = n · μ·AB·H = μT                    （A, B に依存しない）
総分散   = n · AB·σ²H = σ²T                   （A, B に依存しない）
Sharpe   = μT / (σ√T) = μ√T/σ                 （A, B に依存しない）
```

**理想モデル下で TP/SL の選択はシャープを一切改善しない。** 改善の余地は
「理想モデルからの逸脱」にしか存在しない。逸脱は3つに限られる:

| 逸脱 | どの式が破れるか | どの実測に現れるか |
|---|---|---|
| 自己相関（平均回帰／モメンタム） | 増分の独立性 | 実測 `p̂` が理論 `B/(A+B)` からずれる |
| ボラクラスタリング | σ の定数性 | 実測 `E[τ̂]` が `AB·H` からずれる |
| ジャンプ・ギャップ | 連続性（バリアを飛び越す） | 実現損益が `+A/−B` を超過（オーバーシュート） |

### 1.5 コストを入れると内点解が消える ─ 検定可能な診断

往復コスト `c` を入れると `n = T/(AB·H)` 回分かかる:

```
コスト後の総期待値 = μT − c·T/(AB·H)          ← AB について単調増加
```

> **コストがある世界では、期待値基準の最適バリアは常に「外す（持ち切り）」に張り付く。**
> したがって
>
> **格子探索が内点に最適 `(A*, B*)` を返すこと ⟺ 経路依存性が存在すること（またはノイズ）**
>
> という同値関係が成立する。これが本コンポーネントの検定対象であり、
> 「best セルの expR」を成果として報告してはならない理由でもある。

## 2. 識別可能性 ─ 誤差側から必要標本量を見積もる（C26 の作法）

7203.T の実測水準（日次 `σ ≈ 1.8%`）で、曜日効果を `δ = 0.1%/日` と置く。
検定量は `t = δ√n / (σ√H)`。

| 保有期間 H | 曜日あたり標本 n（10年） | ノイズ σ√H | t | 判定 |
|---|---|---|---|---|
| 日中（寄→引, σ≈1.2%） | 60分足730日→**98日** | 1.2% | 1.24 | 境界 |
| 1日 | 490 | 1.8% | 1.23 | 境界 |
| 5日 | 98（非重複） | 4.0% | 0.25 | 不可 |
| 15日（3週間） | 173（3週ごと） | 7.0% | 0.19 | 不可 |

```
t = 2 に必要な標本 n* = (2σ/δ)² = (2×1.8/0.1)² = 1296 日/曜日 = 26年   ← H=1 でも届かない
```

さらに格子探索の**勝者の呪い**が乗る。8×8 格子 × 5曜日 = 320 個の in-sample 最大化なら

```
E[max のみかけ t] ≈ √(2 ln 320) = 3.40
```

> **選択バイアス 3.40 に対し、真のシグナルは 0.19〜1.24。バイアスが信号の 3〜18 倍。**
> `null-calibration.ts` が曜日スロット最適化で測った「エッジゼロで +279%」の床と同じ構図が、
> 格子の分だけ悪化して再現する。

### 2.1 逆に、何なら測れるか

到達確率 `p` は二項なので、`n = 98`（60分足・曜日別・日中）で

```
SE(p̂) = √(p(1−p)/n) = √(0.25/98) = 5.1pp
```

理論値 `B/(A+B)` からの**5pp 超のずれ**は検出できる。`E[τ̂]` も同様に平均の SE で評価できる。
つまり **§1.4 の「逸脱」は測れるが、§1.1 の `S_dow` は測れない**。
これは C26 の「μ は測れない・σ は測れる」の完全な平行構造であり、実装をどちら側に置くかを決める。

## 3. 既存資産の棚卸し ─ なぜ今のアプリでは答えられないか

| 既存 | 何をしている | なぜこの問いに答えられない |
|---|---|---|
| `intraday-excursion.ts` / IntradayExcursionChart | 当日内 MFE/MAE と TP/SL 格子探索、best セル表示 | **完全に in-sample**。ヌル較正なし・曜日次元なし・σ正規化なし。まさに §1.5 で禁じた「best の expR を成果にする」形 |
| `optimal-exit.ts` / `cal-optimal-exit` | 状態 (h, z) の後退帰納で停止境界 z*(h)、インターリーブ2分割 OOS | 週次スケール・曜日は entry timing として固定。境界は内生だが**バリア幅の理論基準線を持たない**（何と比べて良いのか不明） |
| `stop-compare.ts` / StopComparePanel | 中立エントリー × 出口ルール3種（モデル/固定−5%/トレーリングATR）比較 | 曜日次元なし・maxHold 15日固定・%固定でσ正規化なし |
| `null-calibration.ts` | 曜日スロット最適化の偽発見の床（サロゲート） | 対象が「スロット符号」で、**バリア格子を通していない** |
| `weekday-us-interaction.ts` | 曜日別 β の Cochran Q + 置換 | 線形感応度。バリアは非線形な経路汎関数なので枠が合わない |
| `weekday-scan.ts` / `weekday-trade.ts` | 素片分解・週内プラン | 建てる/降りる時刻の最適化。**保有中の経路に反応する規則がない** |

**足りないのは、バリアの理論基準線（§1）を明示的に置き、実測がそこからどうずれるかだけを
曜日別に検定する層**。「best を探す層」はすでに 2つあり、どちらもヌルを通っていない。

## 4. 保有期間ごとの判定 ─ 何を実装し、何を実装しないか

| 保有期間 | 曜日別 TP/SL | 理由 | 本設計での扱い |
|---|---|---|---|
| **日中（寄→引）** | △ 条件付きで有 | 60分足730日＝曜日98日。逸脱指標（§2.1）は SE 5pp で測れる | **主戦場**。層0〜3すべてを実装 |
| **数日（1〜5日）** | × 薄い | `cal-optimal-exit` が z×h で既にカバー。曜日を状態に足すと標本 1/5 で逆効果 | 層0＋層2のみ。「曜日を状態に足しても境界が変わらない」の検定として実装 |
| **数週間** | ✕ 根拠なし | 曜日情報が `δ/(σ√H)` で希釈（t=0.19）。さらに**TP/SL 発火日の曜日はエントリー曜日と無相関**なので、曜日ごとにバリアを変える理論的動機がそもそもない | 曜日から切り離す。層0（設計盤）のみ提供し、実測は `stop-compare` の maxHold 拡張に委ねる |

### 4.1 データ制約

| 足 | 取得上限 | 曜日あたり | 可否 |
|---|---|---|---|
| 5分足 | 60日 | 12日 | ✕ 論外 |
| 60分足 | 730日（≈490営業日） | 98日 | ○ ただし1日6本弱＝到達順の解像度は粗い |
| 日足 | 10年（≈490営業日/曜日） | 490日 | △ **日内の到達順が不明** |

### 4.2 日足の経路曖昧性への対処（必須）

日足で `A, B` が日次レンジと同オーダーだと、初日で決着する確率が高い。しかしその日に
High と Low のどちらが先だったかは日足からは分からない。**同日に両バリアが射程内なら結果が反転する。**
OHLC バックテストの典型的な楽観バイアスなので、片側に決め打ちせず**上下から挟む**:

```
悲観側: 同日両到達 → SL 優先で決着したとみなす
楽観側: 同日両到達 → TP 優先で決着したとみなす
→ 2本の帯として表示し、帯幅が結論を反転させるなら「日足では判定不能」と明記する
```

## 5. 実装設計

### 5.1 層0 ─ 設計盤（推定ゼロ・確実に正しい）

`(A, B, H)` をスライダで動かすと、§1.2 の閉形式で以下を即時表示する。

```
勝率 B/(A+B) ／ 歪度 (A−B)/√(AB) ／ 期待滞在 AB·H ／ トレード分散 AB·σ²H
暦期間 T のシャープ = μ√T/σ（A,B に不変）／ コスト後 = (μT − cT/(AB·H))/(σ√T)
```

同時に「この盤で動かせないもの」を赤字で併記する: **暦時間シャープ**。
これが `AnalysisGuide` の主張と一致し、ユーザーが最初に理解すべき唯一の図になる。

### 5.2 層1 ─ σ正規化（曜日差の正体を暴く）

1. 曜日別に `%` 固定で `(TP%, SL%)` 格子を探索し、best を出す（既存 `intraday-excursion` と同じ計算）
2. 同じデータを `A = TP% / (σ_dow√H)`, `B = SL% / (σ_dow√H)` に変換して再表示
3. **`%` では曜日でばらつく best が、σ単位では一点に集まるか**を並置して見せる

集まれば「曜日別 TP/SL の最適差は σ_dow の差だった」＝曜日別に切る必要なし。
判定は best `(A*, B*)` の曜日間ばらつきを、`%` 単位と σ単位で分散比（F）で比較。

### 5.3 層2 ─ 理論からの逸脱（ここだけが発見の余地）

曜日別に3つの逸脱指標を、理論値との差＋SE で出す。

| 指標 | 理論値 | 逸脱の意味 | 検定 |
|---|---|---|---|
| 到達確率 `p̂` | `B/(A+B)` | 平均回帰（`p̂` 高）／モメンタム（`p̂` 低） | 二項検定＋曜日間 Cochran Q |
| 期待滞在 `E[τ̂]` | `AB·H` | ボラクラスタリング（短くなる） | 平均の t＋曜日間 F |
| オーバーシュート | 0 | ジャンプ・ギャップ（SL が想定より深く滑る） | 超過幅の分布＋曜日間 Kruskal-Wallis |

**曜日間の差だけを検定する**（水準そのものは μ 混入で解釈できない）。
多重性は `benjaminiHochberg`（`stats-significance.ts`）で補正。

### 5.4 層3 ─ ヌル較正＋OOS

1. **サロゲート**: `null-calibration.ts` の曜日ラベル破壊サロゲート生成をそのまま再利用し、
   同一の格子探索パイプラインを流して `best expR` の分布を得る。実測がその分布の何%点かを表示
2. **内点性の検定**: §1.5 より、コスト込みで内点解が出るのは経路依存性がある場合のみ。
   サロゲートでも内点解が同頻度で出るなら、内点性そのものがノイズの産物と結論する
3. **OOS**: インターリーブ2分割（`optimal-exit.ts` と同じ作法）で
   「曜日別バリア／全曜日共通バリア／バリアなし（時間切りのみ）」の3者を比較

### 5.5 ファイル構成

```
新規:
  app/lib/weekday-barrier.ts           理論閉形式・σ正規化・逸脱指標・格子探索
  app/lib/weekday-barrier.worker.ts    格子 × サロゲート（8×8×5×1000本は重い）
  app/components/analysis/WeekdayBarrierChart.tsx
  app/page.tsx  calendar 節に cal-weekday-barrier（cal-optimal-exit の直後）

再利用:
  intraday-core.ts        groupByDay / localMinute / minuteToLabel

                          （incompleteBeta の対称変換修正済み・一元化先）
```

## 6. 成功の定義（何が出れば実装は成功か）

このコンポーネントの成果物は「最適 TP/SL」ではない。以下のいずれかが出れば成功である。

1. **層1 で σ正規化により曜日差が消える** → 「曜日別 TP/SL は不要」を実データで示した
2. **層2 でどれか1つの逸脱指標に曜日差が残り、層3 のヌルを突破する** → 本物の発見。
   ただし FDR 補正後・OOS 後の効果量を必ず併記する
3. **層3 で内点解がサロゲートと同頻度** → **null result として確定**。
   `pf-drift-id` の前例どおり、これ自体が価値ある成果物

期待される既定結果は 1 と 3。7203.T で 2 が出る確率は §2 の数字から低い。

## 7. 非目標（実装しないこと）

- 曜日 × 前夜米国ビン × TP/SL の3重交差。標本が `98/(5×3) = 6.5日/セル` になり議論の対象外
- 数週間保有の曜日別バリア（§4 の理由により理論的動機がない）
- 5分足でのバリア推定（60日＝曜日12日）
- 「best セルの expR」を単独で表示すること。**必ずヌル分布の分位点と並置する**
- トレーリングストップの最適化。`stop-compare.ts` の ATR トレーリングと重複し、
  かつパラメータが1本増えて勝者の呪いが `√(2 ln N)` で悪化する

## 8. AnalysisGuide の必須記載

1. **手法の概要**: TP/SL は「期待値を作る装置」ではなく「滞在時間・勝率・歪度を設計する装置」
2. **数式**: §1 の5式すべて（到達確率の厳密解・μ=0 の4量・Wald・暦時間シャープ・コスト単調性）
3. **用語**: バリア／σ単位（ボラ単位）／任意停止定理／勝者の呪い／サロゲート／オーバーシュート
4. **直感的な例え**: 「TP/SL は蛇口の太さではなく、バケツを取り替えるタイミング。
   流れ込む水の量（μ×時間）は蛇口が決めるので、バケツを小さくしても総量は増えない」
5. **結果の読み方**: 層1の2枚並置／層2の逸脱バーは0を跨ぐか／層3はヌル分布の何%点か
6. **投資判断への活用**: 勝率と歪度は好みで選べる（心理的に続けられる形を選ぶのは合理的）。
   ただし**それでシャープは上がらない**ことを明記。SL の正当化は期待値でなく
   レバレッジ下の破産回避（系C22）と最大DD（系C11）で行う
7. **注意点・限界**: 日足の経路曖昧性（§4.2 の上下帯）／連続時間の閉形式は離散足では近似／
   曜日別 μ は 26年ないと測れない（§2）／内点解はまずノイズを疑う

## 9. 系C28 として原論に追記する内容

```
C28 | 停止規則の中立性（バリアは期待値を動かさない）
     立脚: 公準3（タイミングの自由）＋命題4＋公理2
     測る P の性質: 到達確率 p=(1−e^{νb})/(e^{−νa}−e^{νb})・E[τ]=AB·H
       → 変える q の選択: 建玉の「期待滞在時間」であって符号・大きさではない
     実装: WeekdayBarrierChart
```

導出鎖の要点: C26 が「μ は測れない」を与え、C28 は「μ が測れないなら停止規則で
期待値を作ることもできない」を加える。両者を合わせると、**建玉の設計自由度は
参加（C24）・対象選択（C25）・大きさ（C1/C22）に畳まれ、
出口規則に残るのは分布形の設計とレバレッジ下の生存だけになる。**
