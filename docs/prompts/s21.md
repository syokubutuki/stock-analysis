## FU40: sitemap の手動台帳が腐る

`app/lib/ticker-pages.ts:17` の `PRICE_UNAVAILABLE_TICKERS` は
**`Set(["9613"])` の1件だけ**である。`ticker-pages.test.ts` が固定しているのは
「`9613` が除外されている」と「公開対象が空でない」の2点で、
**新たに取得不能になった銘柄は検知しない**（§0.7⑤）。

S17 は FU20 で「**外部取得を増やさない**」と判断済みで、**この判断は覆さないこと。**
つまり「sitemap の生成時に全銘柄の価格を取りに行く」のは**やらない**。

やること（この順で考えること）:
1. まず「**そもそも検知が要るのか**」を判断する。`/t/[ticker]` は取得失敗時に
   `noindex, follow` の代替表示へ落ちる（§11 R1）。**落ちた先が無害なら、
   台帳そのものを廃止できる可能性がある。** これを先に確かめること
2. 廃止できないなら、**台帳が腐ったことを検知する手段**を用意する。
   ビルド時に取りに行かない範囲で何ができるかを考える
3. **どちらも成り立たないなら「見送り」と書いてよい。** その場合は
   **理由と、復活条件**を `ticker-pages.ts` にコメントで残すこと（S17 が
   `sitemap.ts` にやったのと同じ形）

> **★ null result を救済しないこと**（§9）。「検知できません」が結論なら、
> そう書いて閉じるほうがよい。無理に仕組みを足さないこと。

## FU28: OG画像のフォントサブセットが銘柄台帳と手動同期

`app/t/[ticker]/_fonts/README.md` に書いてあるとおり、サブセットの収録文字（**284字**）は
「`TICKER_PAGE_INSTRUMENTS` **98銘柄**の `name`/`market`/`currency`/`ticker`
＋ 固定文言 ＋ 数字記号英字」に厳密に一致させてある。
`opengraph-image.tsx` は同じ文字列を `OG_FONT_CHARSET` に持ち、描画前に被覆を検査して、
**外れた文字が1つでもあれば数値なしの汎用画像へ退避する**（豆腐は出ない）。

したがって**壊れ方は「静かな退化」である**——銘柄を足すと、その銘柄だけ
数値の入ったカードが出なくなる。画面は壊れず、テストも通る。

やること:
- **`TICKER_PAGE_INSTRUMENTS` から必要文字集合を計算し、`OG_FONT_CHARSET` が
  それを被覆していることをテストで固定する。** 銘柄を足した瞬間に落ちるようにする
- 落ちたときに**何をすればよいか**（`README.md` の焼き直し手順）を
  テストの失敗メッセージから辿れるようにすること
- **フォントの再生成は不要**（現在の98銘柄では被覆できているはず。
  できていなければそれ自体が発見なので報告すること）

**`_fonts/OFL.txt` を動かさないこと。** OFL の再配布条件を満たすために
同じディレクトリに置いてある（README 参照）。
