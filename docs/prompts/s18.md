## A3: Canvas の代替テキスト（本題）
Canvas は中身がアクセシビリティツリーに出ない。**読み上げ利用者には図が存在しない。**

**進め方の指定:**
1. **まず対象を数えて分類して報告すること。** Canvas を持つコンポーネントが何件あり、
   そのうち「図が唯一の情報源」なのは何件か（表や数値が併記済みなら優先度は低い）
2. **全件に長文の説明を書かせないこと。** 各分析は既に AnalysisGuide を持っており、
   「手法の説明」はそこにある。A3 が足すべきは**この図が今この銘柄で何を示しているか**
   （例: 「ラグ1で0.08、以降は95%帯の内側。自己相関は検出されていない」）
3. 実装方式（`role="img"` + `aria-label` / 併設の視覚的に隠したテキスト /
   `<figcaption>`）を**先に決めて確認を取ること**

**罠: aria-label を素の span/canvas に付けるだけでは不十分である。**
S16 の DirectionGlyph は `<span aria-label="上昇">▲</span>` の形で、
ARIA 的には role=generic に aria-label を付けている。Chrome/NVDA では読まれるが
仕様上は保証されない。**S18 で `role="img"` か sr-only テキストへ寄せ直すこと**
（これは S16 の実装を直す作業でもある。1ファイルで済む）。
