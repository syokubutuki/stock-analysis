## 3. 設計書を超えて発展させた部分

**ここが本セッションの実質的な追加分**。すべて実測が理由で、設計書のままでは誤った結論が出ていた。

### 3.1 P1（`sector-factor-select.ts`）で見つかって直したバグ3件

P2 実装後にコードレビューを回して発覚。**いずれも P2 とは独立に P1 の出力を壊していた。**

1. **順位95%CI のブートが点推定と別の因子を使っていた**（重大）。点推定は `factorFor()` 経由で
   basket モードでは leave-one-out になるが、ブート内は `Fcommon`（自分自身を含む全体バスケット）を共用。
   basket を選ぶと b̂ が上振れ・σ_ε が下振れし、**順位CI が点推定と別のスコア定義の上で作られていた**。
2. **ブートが `panel.ret[i]` を `scored` の添字で引いていた**。`olsNW` が落ちた銘柄は `rows` に入らないため、
   1本でも落ちると以降すべての銘柄の順位が**別の銘柄の系列**の上で作られる。`keptIdx` の対応表を追加。
3. **`spreadT` が負になりうる**。`assets` は S=b/σ_ε 順なので両端を取ると、b は最大だが σ_ε が大きく S が
   最下位という銘柄で t が負になり、「b は測れる」の緑カードに負の t が出る。b の最大・最小に変更
   （実測 t は 8.4 → **11.2**）。

### 3.2 設計書の仕様を変えた点（実測が理由）

1. **重複窓の補正を新設**（設計書に無い）。h < ローリング窓だと2窓が標本を共有し
   `Cov(e_t,e_{t+h}) ≈ φ·SE²`（φ=(L−h)/L）が分子に混じって π が機械的に 1 へ寄る。
   分子から `φ·mean(SE·SE)` を差し引く。**補正は観測側だけに掛け、ヌルには掛けない**
   （ラベルをシャッフルすると重複由来の共分散も一緒に消えるため）。
2. **supWald のブロック長 250日 → 63日**。設計書の「窓長と同じ」だと 2400日が10ブロックにしかならず、
   再標本化しても片方のレジームが偏って残る。実測で crit95 が supW の約3倍まで膨らみ**14銘柄すべて検出できなかった**。
   四半期に落として 8 銘柄が q<0.1。
3. **共通成分（等加重バスケット）の検定を追加**（設計書に無い）。§3.3 の発見はこれが無ければ出なかった。
4. **トラストスコアを横断中心化してから測る**。設計書の式を素直に実装したら**全14銘柄が負**になり π=0.97 と矛盾。
   原因は全銘柄の b が揃って上昇していたこと（共通の水準変化は順位を動かさないので選別には無害）。
5. **ローリングでは市場への直交化を省いた**（Frisch-Waugh により b と残差は不変）。
   L2-D の符号分割は `1{F<0}` の中身が変わるため必ず直交化する。
6. **交互作用回帰に水準ダミー D を追加**（設計書の式には無い）。D と F·D は相関するので δ に水準差が混入しうる。
7. **リバランス間隔の陳腐化項を「実測回転率」ベースに置換**。設計書の `κ·σ_F²·Var(β)` は単位が閉じないため、
   露出保持率の平均 `(τ/Δt)(1−e^{−Δt/τ})` とペア間の実測 L1 回転率に置き換えた。
   **残る仮定は m（セクターの年率期待リターン）だけ**で、`ASSUMED_SHARPE` と同じ扱い（画面に「仮定」と明示）。
8. **計算をまるごと Worker へ**（設計書 §7.7 は L2-C だけの想定）。`setTimeout(…, 0)` は実行を遅らせるだけで
   逃がさず、刻み5日・窓500日で数秒フリーズし「計算中」の表示すら描画されなかった。
   設計書の「Worker に価格を渡さない」制約は、計算が全部 Worker に来た時点で `buildPanel` が1回しか
   走らないので**不要になった**。
9. **supWald の W(s) 経路を lightweight-charts に**。横軸が分割点の日付なので CLAUDE.md の規約に反していた。
10. **`RollPoint` を `Record<string,number>` でなく銘柄インデックス配列に**。描画でそのまま使え、複製も軽い。
11. **分割点探索を累積和（prefix sum）で O(1) 化**。素直に書くと 16M 回帰で動かないが、
    `X'X`/`X'y`/`y'y` の累積和 + 3×3 逆行列で全体 0.9 秒。

### 3.3 実測から出た「発展」＝当初の見立ての訂正

**P1 の申し送り「b の律速は統計誤差でなく時変性」は、銀行セクターについては誤りだった。**

```
π(1年) = 0.97 [0.81, 1.03]   ヌル95% = 0.06     ← 順位はほぼ恒久的
上位5本の1年後生存 84%（完全ランダム 36%）/ rankIC(S) = 0.84
半減期 2170日（標本長 2400日 ≒ 観測範囲で減衰が見えない）
```

同時に supWald は構造変化を検出する（8/14 銘柄、分割点は 2020-02〜2021-12 に集中）。
矛盾しないのは、検出された変化が**共通成分**だったから（等加重バスケット自体に p=0.017、b 0.57→0.79、
有意10本中9本が同符号）。**全員の身長が伸びても背の順は変わらない。**

帰結は非対称になる。

| | 影響 |
|---|---|
| 選別（相対） | **無傷**。P1 の S 順位をチルトの根拠に使ってよい |
| 建玉サイズ（b の絶対値） | **窓依存**。10年窓の b は「別レジームの平均」 |

二段収縮の効果はウェイト総変動 1.1% とほぼゼロ。π が高いので当然で、
**この層の価値は「ウェイトを動かしたこと」ではなく「動かさなくてよいと確認したこと」**にある。
律速は時変性ではなく、① m（金利観）の当否 ② 採用5本の加重市場β 1.27 の2つに移った（→ ★1）。

### 3.4 副産物: basket モードのほうが分割点の解釈が素直

leave-one-out 因子に切り替えると、検出された分割点が政策日に寄る。

```
2024-03-01（マイナス金利解除・YCC撤廃 まで18日）2票   ← etf モードでは検出されない
2022-12-19（YCC 変動幅拡大 まで1日）
2023-07-25（YCC 運用柔軟化 まで3日）
```

ETF 因子は各銘柄自身を時価加重で含むため、銘柄固有の構造変化が因子側にも同時に現れて差が相殺される。
**銘柄ごとの構造変化を見たいときは basket（L-O-O）に切り替えること。**
π（横断の持続性）は etf/basket でほぼ変わらない。
