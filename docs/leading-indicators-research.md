# 銀行株の短期先行指標の探索（金・ビットコイン・金利・為替・信用・海外金融株）

作成日: 2026-10-21 ／ コード: `research/leading-indicators/`（Python）・アプリ `causal-cross-asset`（因果節）

## 0. 結論（先に）

- **金・ビットコインは、銀行株の短期の値動きの先行指標になっていない。**
  金は寄り付きの窓とすら関係が見えない（t=−1.4）。BTC は窓と相関する（t=+5.2）が、米国株の動きを除くと t=+2.4 まで落ち、寄り後は全く効かない。
- **寄り付きの窓（前日終値→当日始値）は、前夜の海外の動きで約3割説明できる。**
  効いているのは米金融株（XLF/KBE/KRE/JPM、t=10〜14）・米金利（5年・10年、米国株を除いても t≈9）・VIX（逆向き）・欧州金融株。
  6変数の回帰で時間外 R² 28%（メガバンク3行 31%、地銀5行 36%、1615.T 27%）。ただし窓は寄った瞬間に終わっているので、寄りで建てる人には取れない。
- **寄り後（寄り→引け／寄り→翌寄り／寄り→5日後）に先行する指標は、族補正すると見つからない。**
  30候補×2特徴×3時間帯の検定で、円環シフトの最大|t|と比べて p<0.05 になるのは、
  「S&P500 前夜 → 寄り→引け」の**負**の関係（米国高の翌日は寄りで行き過ぎて日中に戻す）だけで、それも銘柄により p=0.03〜0.09 の境界。
  この現象はデリスク研究（`docs/bank-derisk-research.md`）で既に見つかっており、コスト10bpで半減・20bpで消える。
- **2008〜09年だけは違った。** 2006年からの長期データでは、米金融株・S&P500・ハイイールド債・ユーロ円が寄り→引けまで先行していた（t=5〜6）。
  年別に分けると、それは 2008〜09年の2年間だけで、2010年以降は消えるか逆符号になる。事前の VIX が30以上の日に絞っても、2010年以降は再現しない（むしろ逆向き）。
  時代限定の現象として扱う。

## 1. 前提

| # | 前提 |
|---|---|
| ① | 判断は寄り付き直前。候補 X は「日付が当日より厳密に小さい最新の足の終値」（先読み防止。米国の終値は JST 朝5〜7時、BTC の日足は JST 9時＝UTC0時、FX は 8〜9時に閉じる）。 |
| ② | 特徴量は判断時刻どうしの間の変化（d1）と5日変化（d5）。金利は水準差（%pt）、他は対数変化。 |
| ③ | ターゲットは 窓 gap=ln(O_D/C_{D−1})、寄り→引け id=ln(C_D/O_D)、寄り→翌寄り oo=ln(O_{D+1}/O_D)、寄り→5日後 f5=ln(O_{D+5}/O_D)。 |
| ④ | 対象はメガバンク3行の等加重を主に、1615.T・個別3行・地銀5行（8331/8354/7186/5831/8309）で再確認。 |
| ⑤ | 価格はアプリと同じ `fetchStockSource` ＋ `repairPriceGlitches({ticker})` を通した（`research/bank-derisk/fetch.mts` / `fetch_max.mts`）。 |

## 2. 候補

コモディティ（金・銀・銅・原油・天然ガス）、暗号資産（BTC・ETH）、米金利（3か月・5年・10年・30年）、債券ETF（TLT・HYG・LQD）、
為替（ドル円・ユーロ円・豪ドル円・DXY）、海外金融株（XLF・KBE・KRE・JPM・EUFN）、VIX・MOVE、S&P500・日経先物CME・香港・上海・ユーロストックス50。計30（アプリは26に絞った）。

## 3. 検証の経過

| 段階 | 内容 | 結果 |
|---|---|---|
| scan.py | 全候補×d1/d5×4ターゲットの単回帰（HC3、f5 は NW）、S&P と日経先物を対照に入れた t、拡大窓の時間外 R²、年別の符号 | 窓は強い（上記）。寄り後の最大は S&P→id t=−2.9、ユーロ円→oo t=+2.7、LQD d5→f5 t=−3.5 |
| scan2.py A | 円環シフト500回の max|t| で族補正 | メガ3行: 寄り後で p<0.05 は 0。地銀5行・1615.T: S&P→id のみ p≈0.03 |
| scan2.py B | 窓の前進選択（拡大窓 OOS） | XLF → 米5年金利 → VIX → EUFN → 香港 → ETH で R² 0.22→0.32。金は選ばれない |
| scan2.py C | 1日古い情報（日本の引け時点で既知）→ 翌朝の窓 | 最大 |t|=2.4（ユーロ円）。持ち越し判断には使えない |
| scan2.py D | 大きく動いた日（|z|>2）の条件付き平均 | 金・BTC の急騰/急落後の日中は ±0.2〜0.4% の範囲で0と区別できない |
| oot.py | 2006-09〜2016 の時間外検証 | 米金融株・S&P・HYG・ユーロ円・銅が id で t=3〜6。2017〜では消える |
| yearly.py | 年別の t | 2006〜16 の先行性は 2008・2009 年だけ。2010 年以降は ±2 以内 |
| regime*.py | 事前 VIX で層別 | VIX≥30 でも 2010〜16・2017〜 は逆符号（t=−1〜−3）。危機一般ではなく 2008〜09 年限定 |

試行数の開示: 30候補×2特徴×4ターゲット＝240検定（族補正は売買可能な180検定で実施）、ターゲット銘柄群6、層別3通り。

## 4. アプリでの表示（`causal-cross-asset`）

- 結論カード3枚（窓は説明できる／寄り後は族補正で何本残るか／金とBTCの値）
- 次の寄り付きの窓の目安（S&P500・XLF・米5年金利・VIX・EUFN・ドル円の回帰、寄与の内訳、±1σ）。米国の終値が最後の日本立会日より古いときは「朝6〜7時に更新」と出す
- 候補×4時間帯の t 値ヒートマップ（族補正 p<0.05 は太枠）、米国株を除いた窓の t
- 行クリックで詳細（統計表・250日ローリング相関〔lightweight-charts〕・急変日の条件付き平均）
- 族補正（円環シフト300回）は Web Worker（`cross-asset-lead.worker.ts`）。ライブラリの数値は Python と一致を確認（`research/leading-indicators/check-lib.mts`）

## 5. 気づいたこと（今後の材料）

- BTC と銀行株の**窓**の相関はここ1年で 0.36 まで上がっている（2024年前半は 0 前後）。リスク選好の共通因子としての連動が強まっている。ただし寄り後には効いていない。
- 米金融株と邦銀の窓の連動は 2023〜25 年に弱まった（XLF の t が年14→2〜4）。日本独自の金利要因で邦銀が米銀から切り離された時期と整合する。
- 日足では「日本の取引時間中のアジア時間の金・BTC の動き」が前夜1日の変化に混ざる。日中足で時刻を揃えた検証は未実施。
