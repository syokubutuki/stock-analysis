# セクター内選別 ─ 高相関を前提に「どの銘柄を買うか」を決める設計書

対象: 特定セクター（当面は**銀行**）に意図的に集中し、そのセクターにドリフトがあると考えている投資家。
分散の放棄は**前提**であって欠陥ではない。本設計はその前提を受け入れたうえで、
**セクター内のどの銘柄を・どの比率で持つと成長率が最大になるか**を、測れる量だけで決める。

新規: `app/lib/sector-factor-select.ts` / `app/lib/sector-rate-sensitivity.ts` /
`app/components/analysis/SectorFactorSelectChart.tsx` / `/portfolio` の `pf-sector-select` /
`universes.ts` の `sec-bank` / 原論の**系C29**。

---

## 0. 一言結論（これを画面の最上段に出す）

```
期待リターンの銘柄間差は測れない（C26）。
ファクター感応度の銘柄間差は測れる。
だから選別は μ̂ でなく b̂ で行い、順位は b/σ_ε でつける。
```

同じ3年のデータで、Δμ=5pp の識別には **144年**かかるのに、Δb=0.30 は **t≈9** で分離できる。
この非対称性がセクター内選別を成立させる唯一の足場であり、本コンポーネントの存在理由でもある。

## 1. 問題設定 ─ この賭けの構造を式にする

投資家の主張は「金利上昇局面では銀行セクターにドリフトがある」。これは個別銘柄への賭けではなく
**ファクターへの賭け**である。ならば個別銘柄のリターンは次のように分解される。

```
r_i,t = α_i + c_i·M_t + b_i·F_t + ε_i,t

  M_t : 市場ファクター（TOPIX 等）
  F_t : セクター・ファクター（市場に直交化した銀行業指数）
  b_i : セクター感応度 ← 本設計の主役
  ε_i : 固有リターン（この投資家は何の見解も持っていない部分）
```

投資家の前提は `E[F] = m > 0`（金利上昇局面のセクター・ドリフト）。市場中立で見るなら

```
E[r_i] − c_i·E[M] = α_i + b_i·m
```

α_i は C26 により**測れない**（μ の識別限界がそのまま α に効く）。よって

> **この投資家の枠組みの中では、期待リターンの銘柄間差は b_i にしか宿らない。**

これが本コンポーネントの出発点であり、同時に**限界の宣言**でもある。
銘柄選別は `m` の**増幅器**であって、`m` そのものを作り出さない。

## 2. 既存資産の棚卸し ─ なぜ今のアプリでは答えられないか

| 既存 | 何をしている | なぜこの問いに答えられない |
|---|---|---|
| `pf-capm`（CapmSmlChart） | 市場 β と Jensen の α | ファクターが**市場のみ**。銀行同士は β がほぼ同じで並び、セクター内の差が潰れる。α は C26 により測れない |
| `pf-drift-id`（DriftIdentifiability） | μ̂ の識別限界・勝者の呪い | 「μ で選ぶな」までは言うが、**代わりに何で選ぶか**を出さない。本設計はその答え |
| `pf-selection-tilt`（SelectionTilt） | 特性ソートの前向き検証 | 特性が価格由来（モメンタム/低ボラ等）で、**ファクター感応度が特性に入っていない** |
| `pf-frontier` / `pf-resampled` | 平均分散最適化 | 入力 μ̂ が推定不能な量。銀行 15 本の Σ は高相関でほぼ特異、解が暴れる |
| `pf-corr-drag` / `pf-growth-drag` | 相関が成長率を削る | 「相関が高い＝悪い」で終わっており、**高相関の中身がファクターなら削られていない**ことを言わない |
| `cross-sectional-edge` | 市場中立ロングショートの IC | ロングオンリーの「床の底上げ」ではない。集中を前提にしていない |

**足りないのは、1ファクター模型を明示的に立てて b を推定し、b の識別可能性・安定性・前向き有効性を検定する層**。

## 3. 理論 ─ 5つの導出（実装はこの5式に還元される）

### 3.1 期待リターンの縮約

セクター内では市場感応度 c_i の差は小さいので、市場を除いた超過で見る。

```
E[r_i^ex] = b_i · m        (α_i は測定不能ゆえ 0 と置く＝C16 の誤差割引の極限)
σ_i²      = b_i²σ_F² + σ_ε,i²
```

### 3.2 識別可能性の非対称性（C26 の裏返し）

```
μ について : SE(μ̂)   = σ / √T                    … 観測頻度で縮まない（両端2点の恒等式）
b について : SE(b̂)   = σ_ε / (σ_F · √T)          … 観測頻度で縮む（回帰の情報が毎日入る）
```

数値で確認する（日次・T=750≒3年、銀行の典型値）。

```
σ_ε ≈ 1.0%/日, σ_F ≈ 1.6%/日
  → SE(b̂) = 0.010 / (0.016 × 27.4) ≈ 0.023
  → b=1.30 と b=1.00 の差 0.30 は  t = 0.30 / (0.023·√2) ≈ 9.2

一方 μ は σ=30%/年・T=3年 で SE(μ̂) = 17.3pp/年
  → Δμ=5pp は  t ≈ 0.2   （t>2 に必要な期間 T* = (2×0.30/0.05)² ≈ 144年）
```

> **同じデータ・同じ銘柄で、μ の差は見えず b の差ははっきり見える。**
> この一対を必ず**並べて**画面に出す。選別基準を b に移す理由がここでしか説明できない。

ただし b̂ の真のリスクは**統計誤差ではなく構造の時変性**に移る（§6.1 で検定する）。

### 3.3 ランク基準 `S_i = b_i / σ_ε,i` の導出

シャープレシオを b と σ_ε で書き直す。

```
SR_i = b_i·m / √(b_i²σ_F² + σ_ε,i²)
     = m / √(σ_F² + (σ_ε,i / b_i)²)          ← 分子分母を b_i で割った
```

ここから2つの帰結が出る。

**(a) m がランク付けから消える。**
`m` は全銘柄共通のスカラーなので、SR の**順序**は `σ_ε,i / b_i` の小ささだけで決まる。
つまり投資家が知り得ない「金利上昇の強さ」を推定しなくてよい。必要なのは **`m > 0` の符号だけ**。

```
ランク基準:  S_i = b_i / σ_ε,i        （＝情報比 information ratio そのもの）
```

**(b) b が最大の銘柄を選ぶのは誤り。**
b の大きさはレバレッジと等価（`2b・半分の建玉` は `b・満額の建玉` と同じ露出）。
大きさは**サイジングで作れる**ので、選別で問うべきは「同じ露出を、**払われないリスク**をより少なく得られるか」。
地銀は b が高い傾向にあるが σ_ε も高く、S では必ずしも勝たない。

### 3.4 最適ウェイト `w_i ∝ b_i / σ_ε,i²`

1ファクター模型 `Σ = σ_F²·bb' + D`（D = diag(σ_ε,i²)）、期待超過 `μ = b·m` の下で
最大シャープ解 `w ∝ Σ⁻¹μ` を Sherman–Morrison で展開すると

```
Σ⁻¹ = D⁻¹ − (σ_F² · D⁻¹bb'D⁻¹) / (1 + σ_F²·b'D⁻¹b)

Σ⁻¹b = D⁻¹b · [ 1 − σ_F²·b'D⁻¹b / (1 + σ_F²·b'D⁻¹b) ]
      = D⁻¹b / (1 + σ_F²·b'D⁻¹b)                    ← b に比例するスカラー倍

∴  w_i ∝ b_i / σ_ε,i²
```

**均等でも b 順でもなく、固有分散の逆数で重みづける**。これはファクター模倣ポートフォリオ
（factor-mimicking portfolio）の重みであり、「露出あたりのリスクを最小化する持ち方」。

実装では long-only 制約（負を 0 にクリップ）と1銘柄上限（既定 35%）を掛ける。
制約後は厳密最適でなくなるため、**制約なし解との成長率差を必ず併記**する。

### 3.5 「ファクターは集中、残差は分散」の定量

高相関 ρ≈0.7 の**中身**は投資家が欲しい共通ファクターである。それを除いた残差相関 ρ_ε は 0.2〜0.3 に落ちる。
ここに、露出を1ミリも削らずに拾える利得がある。

```
仮定: 分散の 70% がファクター由来・30% が固有、ρ_ε = 0.25、k 銘柄等加重

固有分散 → 0.30 × (1 + (k−1)ρ_ε) / k
k=1 : 0.300  → 総分散 1.000  σ 100.0%
k=3 : 0.150  → 総分散 0.850  σ  92.2%
k=5 : 0.120  → 総分散 0.820  σ  90.6%
k=8 : 0.105  → 総分散 0.805  σ  89.7%
k=15: 0.088  → 総分散 0.788  σ  88.8%
```

b は不変のまま σ だけ落ちるので、シャープは `1/0.906 = ×1.104`（k=5）。
ケリー成長率 `g* = SR²/2` は SR 0.50 → 0.55 で **年率 +2.7pp**。

> **「1本に集中」は、このタダで拾える +2.7pp を捨てている。**
> 正しい標語は「**セクターに集中し、セクター内では分散する**」。
> k は 5〜8 で頭打ち（限界利得が σ で 1pp を切る）。

このパネルは既存の `growth-drag.ts` / `GrowthIntuitionPanel` と同じ言語で書き、
「相関ドラッグ」を**ファクター由来（払われている）**と**固有由来（払われていない）**に割る点だけが新しい。

## 4. 何がわかるか ─ 出力と問いの対応

| # | 投資家の問い | 出力 | 答えの型 |
|---|---|---|---|
| Q0 | **そもそも銀行セクターは金利の賭けなのか** | セクター因子を金利プロキシに回帰した R²・符号 | R² が低ければ前提が崩れる。**最初に出す** |
| Q1 | 銘柄ごとの金利/セクター感応度はいくつか | b̂ ± SE・t・95%CI・R² の一覧 | 数値と誤差。C26 の μ̂ 表と**並置**して非対称性を見せる |
| Q2 | どの順に買うべきか | S = b/σ_ε のランキング（JS収縮後・順位95%CI） | 順位と、その順位がノイズで何位ぶれるか |
| Q3 | どの比率で持つべきか | w ∝ b/σ_ε² の推奨ウェイト（制約付き/なし） | 具体的な % |
| Q4 | 何本持てばよいか | k を振った σ_p・SR・g* 曲線 | 5〜8本で頭打ちという打ち止め点 |
| Q5 | この順位は来年も同じか | ローリング b・順位 IC・期間分割 b | 安定なら選別可、不安定なら等加重へ |

| Q7 | 高相関を逆に使えないか | 残差 z によるローテーションの WF 検定 | 使えるなら入れ替え規則、駄目なら封印 |
| Q8 | 決算資料側の裏づけは | ΔNII/時価総額 と b̂ の散布（Spearman） | 統計とファンダが一致する銘柄＝本命 |

#### 5.1.3 セクター因子の構成（self-inclusion バイアスの除去）

ETF ではなく等加重バスケットを因子に使う場合、銘柄 i を自分自身を含むバスケットに回帰すると
b̂_i が上方に偏る（N=16 なら自己ウェイト 1/16 ぶん）。**leave-one-out** で必ず除く。

```
F_t^(-i) = mean_{j≠i} r_j,t   をそれぞれの i について作る
```

ETF（1615.T）を使うときも、構成に i が含まれるため厳密には同じ問題がある。
ETF モードでは自己ウェイトが時価加重で小さい（メガバンクは無視できない）ため、
**ETF モードでも「自己ウェイト概算値」を診断に表示**し、大きい銘柄には注記を出す。

#### 5.2.1 アルゴリズム（逐次）

1. **整列**: `alignReturns` で全銘柄＋因子の対数リターンを共通営業日に整列。`^TNX` は
   `alignJpUs` で**前営業日の米国変化 → 当日の日本**に対応させる。欠損日は共通部分のみ採用。
2. **直交化**: `F_t` を `M_t` に OLS 回帰し、残差を新しい `F_t`（市場と無相関なセクター因子）。
   `factorMode="rate"` のときは金利プロキシ変化を同様に直交化して `F_t` とする。
3. **前提診断 L0**: `F_sector` を `ΔRate` に回帰 → `rateR2` / `rateBeta` / `rateT`。
   併せて生相関 `ρ̄`・残差相関 `ρ̄_ε`・`factorShare` を算出。
4. **銘柄別回帰 L1**: 各 i について `r_i = α + c·M + b·F^(-i) + ε` を OLS。
   標準誤差は Newey–West（lag = 5）。`σ_ε = std(ε)·√252`、`S = b/σ_ε`。
5. **収縮**: James–Stein を横断平均 b̄ に向けて適用。
   `b_JS = b̄ + max(0, 1 − (N−3)·s̄² / Σ(b_i−b̄)²)·(b_i − b̄)`、`s̄² = mean(SE_i²)`。
   縮小率をそのまま「見かけの差のうちノイズの割合」として表示する。
6. **順位CI**: 移動ブロック・ブートストラップ（ブロック長 21）で `b̂` を再推定し、各銘柄の順位分布 → 95%CI。
7. **ウェイト**: `w_i ∝ b_i/σ_ε,i²` を正規化 → 負をクリップ → 上限 `maxWeight` で反復キャップ → 再正規化。
8. **安定性 L2**: `rollWindow`/`rollStep` で b の経路。前半窓と後半窓の順位 Spearman = `rankIC`。
   `F_t > 0` の日と `< 0` の日で b を分けて Wald 検定（`bUp` vs `bDown`）。
9. **WF 検証 L3**: `rebalanceDays` ごとに、**その時点までの窓のみ**で b・σ_ε を再推定し、
   `S` 上位 `topK` を `w ∝ b/σ_ε²` で保有 → 次のリバランスまで。床は同ユニバース等加重。
   超過は NW 頑健 t、シャープ差は Jobson–Korkie–Memmel。
   **順列ヌル**: 各リバランスで k 本を**ランダムに**選ぶ試行を `nPerm` 回 → Δμ のヌル分布と p 値。
   **勝者の呪い**: 「真の b は全銘柄同一」というヌル下でブートし `E[b̂max − b̄]` を実測。
   同じ操作を μ で行った値を並置（`SE·√(2 ln N)` の桁で圧倒的に大きくなるはず）。
10. **集中曲線 L4**: k=1..N について `w ∝ b/σ_ε²` の上位 k で `σ_p`・`SR`・`g* = SR²/2` を計算。
11. **残差ローテーション L5**: `z_i,t = Σ_{s=t−59}^{t} ε_i,s / (σ_ε,daily·√60)` を作り、
    `z` と次期（21日）残差リターンの順位相関 IC を測る。ブロック順列でヌル。
    **IC が有意でなければ `enabled=false` にして機能ごと画面から畳む**（使えないものを出さない）。

#### 5.2.2 計算量と Worker

N=16・T=2500・`nPerm=500`・`nBoot=1000` で、WF ＋ 順列が支配的。
概算 500 × 40 リバランス × 16 銘柄の回帰 ≒ 32万回の小回帰。メインスレッドで 1 秒を超える見込み。

**この表の意味**: b̂ は「価格が結果として何を織り込んだか」の要約にすぎない。
b が高い理由が①本当に金利感応度が高い、②単に高ボラで何にでも大きく動く、のどちらかを
価格データだけでは切り分けられない。ΔNII/時価総額 との**突き合わせがその切り分け**になる。

```

  左上 = b は高いがファンダの裏づけなし → 単なる高ボラの疑い
  右下 = ファンダは強いが価格が反応せず → 出遅れ or 別の重石（ΔEVE を確認）
  左下 = 対象外
```

Spearman 相関と、右上象限の銘柄の明示を出力する。表が空なら L6 は非表示。

### 5.6 AnalysisGuide 要点

CLAUDE.md の7項目に加え、原論の標準ブロックを末尾に置く。

1. **手法の概要**: 「上がる銘柄を当てる」のではなく「あなたの見立ての増幅率が高く、無駄なリスクが少ない銘柄を選ぶ」
2. **数式**: §3 の5式を省略せず（分解・SE の非対称性・S の導出・Sherman-Morrison・集中曲線）
3. **用語**: ファクター感応度 / 固有ボラ / 情報比 / James-Stein 収縮 / ファクター模倣ポートフォリオ / IRRBB・ΔNII・ΔEVE / 預金ベータ
4. **例え**: 「b はエンジンの排気量ではなく**ギア比**。同じアクセル（金利上昇）でどれだけ加速するか。
   ギア比が高い車が速いのは坂を登るときだけで、下りでも同じだけ速く落ちる」
5. **読み方**: R² が低ければ前提を疑う／b の CI が重なる銘柄は順位に意味がない／`verdict` が赤なら等加重へ
6. **投資判断**: 推奨ウェイト表をそのまま発注に使う／k=5〜8／b が高い銘柄を選ぶのではなく S で選ぶ
7. **注意点**: §9 の落とし穴チェックリストを要約

## 6. 検証層 ─ どこで嘘が入るか

### 6.1 b̂ の真のリスクは統計誤差ではなく時変性

§3.2 の通り SE(b̂) は小さい。よって「推定できるか」はもう問題ではなく、
**「推定した b が来期も同じか」**だけが問題になる。b が動く原因は実在する。

- バランスシートの入れ替え（有価証券デュレーションの短縮・貸出構成の変化）
- 金融政策レジームの転換（マイナス金利期と解除後で b の水準も符号も変わりうる）
- 資本政策・再編（統合、政策保有株の売却）

→ **L2 の `rankIC`（前半窓の b 順位 と 後半窓の b 順位 の Spearman）がこの分析の生命線**。
`rankIC` が 0 近傍なら、b で選ぶ行為は過去のノイズを並べ替えているだけになる。
画面上で `rankIC` を**単独の大きな数字**として出し、低い場合は L1 の推奨ウェイトに警告を重ねる。

### 6.2 b の選別にも勝者の呪いはある（ただし桁が違う）

N 銘柄から b̂ 最大を選ぶと、真の b が全銘柄同一でも `E[b̂max − b̄] ≈ SE_b·√(2 ln N)`。
N=16・SE_b=0.023 なら **約 0.054**。b の水準 1.0 に対して 5% の上振れ。
一方 μ で同じことをすると SE_μ=17pp なので **約 40pp/年**。

> **この2つを並べて出すことが、本コンポーネントの最も重要な1画面**。
> 「選別は原理的に不可能」ではなく「**μ で選ぶのが不可能で、b で選ぶのは可能**」を数値で示す。

### 6.3 誠実な既定結果

`selection-tilt` / `drift-id` と同じ規律を敷く。

```
WF の Δμ が t < κ（既定2）、または順列ヌルの p > 0.1  →  verdict = "床と区別できない"
  → 画面は赤バッジ＋「銀行等加重（または銀行ETF 1615.T）を持て」を推奨として出す
  → L1 の推奨ウェイトは灰色化し「参考値」と明示する
```

複数の設定（因子モード×因子ソース×窓長×topK）を試すこと自体が多重検定なので、
**試した設定数 M を画面に表示し、BH-FDR で補正した q 値**を判定に使う（`test-ledger.ts` / `edge-book.ts` の流儀）。

### 6.4 生存者バイアス

地銀は再編で消えた行が多く、現在の `sec-bank` は**過去の勝者リスト**。
`cross-sectional-edge.ts` の point-in-time 診断を移植し、
「全 N 行が終端まで生存 → 生存者バイアスあり」を警告として出す。
`constituents.ts` の器（`delist-zero` / `merger` の終端処理）に将来つなげられるよう、
`computeSectorSelect` は `membership` 引数を**将来の拡張点としてコメントで明記**しておく。

## 7. 価格データで測れない部分（実務で最も効く層）

b̂ は結果の要約であり、その中身は決算資料側にある。金利上昇局面で銀行間の差を作る駆動因子。

| 駆動因子 | 高 b になる方向 | どこで確認するか |
|---|---|---|
| **預金ベータ** | 個人流動性預金の比率が高い＝利上げ時に調達コストが上がりにくい＝NIM 拡大が大きい | 決算説明資料の預金構成・預貸金利回り推移 |
| **貸出の金利改定サイクル** | 変動金利・短期貸出の比率が高い＝即座にリプライス | 貸出金の金利改定期間別残高 |
| **有価証券デュレーション** | 短い＝利上げ初期の評価損が小さい。長いと b が正でも先に殴られる | ΔEVE(+100bp)、その他有価証券評価差額金 |
| **手数料収益比率** | 高い＝金利依存度が低い＝ b が小さい | 業務粗利益の内訳 |
| **信用コスト感応度** | 中小企業向け比率が高いと利上げの負の側面が遅れて効く | 与信費用・貸出先構成 |
| **外貨調達比率** | 日米金利差の影響を受ける | 外貨資金収支 |

最も再現性のある1指標は **IRRBB 開示の ΔNII(+100bp)**。これを時価総額で割ったものが
「利上げ 100bp の取り分」であり、**b のファンダメンタル版**にあたる。
併せて ΔEVE(+100bp)/Tier1 が「利上げ初期の痛み」で、**この2つは符号が逆になりやすい**
（貸出で儲かる行ほど債券も抱えている）。両方を出して初めて判断できる。

§5.3 の静的表はこれを手入力で受け取り、L6 で b̂ と突き合わせる。

P0 を実装して実データで回したところ、**設計時に想定していなかった4点**が出た。
いずれも P1 以降にそのまま効くので、上の仕様に対する正式な変更として記録する。

### 8b.1 【重大】残差相関 ρ̄_ε は「パネル内平均」からは原理的に測れない

§3.5 の分散利得は ρ̄_ε に依存するが、**等加重バスケット（leave-one-out）の残差から ρ̄_ε を測っては
いけない**。等相関 ρ・分散 σ² の残差 e_i を横断で中心化すると

```
Cov(ẽ_i, ẽ_j) = σ²(ρ−1)/N,   Var(ẽ_i) = σ²(N−1)(1−ρ)/N
⇒ corr(ẽ_i, ẽ_j) = −1/(N−1)        （ρ が完全に消える）
```

つまり測定値は真の ρ に関係なく **−1/(N−1) に張り付き、情報がゼロ**になる。
実データでも basket モードの ρ̄_ε は N=13 で **−0.074**（−1/12 = −0.083）となり、この恒等式を再現した。
初版の実装はこれをそのまま報告し、N_eff = 116.6（13銘柄なのに！）という無意味な値を出していた。

**変更**: ρ̄_ε は **常にパネル外の因子（セクターETF 1615.T）の残差から測る**。
`factorSource` が basket でも、ρ̄_ε だけは ETF 残差を使う（b の推定は leave-one-out のまま）。
ETF が無ければ `meanRhoResid = null` / `rhoResidSource = "none"` として**識別不能を明示**し、
分散利得も出さない。`ReturnPanel` には factorSource に関わらず常に ETF を載せる。

> ETF も構成に自銘柄を含むため ρ̄_ε は下方に偏る。よって**分散利得は上界**として読む。
> これは警告文として画面に出す。

### 8b.2 【重大】1点の価格破損が全回帰を破壊する

`1306.T`（TOPIX ETF）は **2026-03-30〜03-31 の2日だけ価格が 1/10** になっている
（375.49 → 36.93 → 36.44 → 381.86）。この2点だけで

| | 破損あり | 修復後 |
|---|---|---|
| σ(1306.T) 日次 | **12.14%**（年率193%） | 1.32%（年率21%） |
| 8306.T の市場β | **0.03** | 1.24 |
| 平均の市場シェア | **3.5%** | 45.8% |

回帰の分母 Var(M) が100倍になるため β がゼロに潰れる。**気づかなければ「銀行は市場と無関係」
という完全に誤った結論**が出ていた。

**変更**: `repairGlitches()` を新設し、`buildPanel` で**因子・銘柄すべての系列に必ず適用**する。
判定は「大ジャンプが数日以内にほぼ同じ大きさで戻る」に限定（`|r_t|>0.3` かつ
`t..s` の累積が `|r_t|` の20%未満に戻る `s` が5営業日以内、かつ `|r_s|>0.3`）。

真の暴落・ストップ安は数日で完全には戻らないため誤検出しない。修復点数は診断に出す。

> **これは P0 固有の話ではない。** 同じ破損は他の分析にも効いているはずで、
> `1306.T` をベンチマークに使っている既存コンポーネント（`capm-sml` 等）は要確認。**follow-up 課題**。

#### 【解決済み 2026-07-30】修復を取得層に一元化した

follow-up を実施。被害は予想通り P0 に限らなかった。`7203.T` の市場βを実測すると

コンポーネントはすべて同じ被害を受けていた（`capm-sml` / `efficient-frontier` /

## 8c. P1 実装記録（2026-07-31 完了）── 銘柄別 b̂ と S ランキング

### 8c.1 仕様変更: μ 側の見せ方を「必要年数」から「勝者の呪いのヌル比較」へ

初版は「1位と最下位の μ̂ の差を t>κ で識別するのに必要な年数」を出していたが、
**これは誤り**。最大−最小は選抜バイアスが最も強く乗る統計量なので、そこから T* を逆算すると
「7年で識別できる」という数字が出て、**μ が測れるかのように見えてしまう**（C26 の主張が壊れる）。

正しい問いは逆で、「観測されたスプレッドは、真の μ が全銘柄同じでも出る大きさか」。

```
ヌル期待スプレッド  E[max−min] ≈ SE(μ̂)·2√(2 ln N)      （C26 の勝者の呪いと同じ極値近似）
```

実測（sec-bank）:

| 窓 | 観測 μ̂ スプレッド | ヌル期待 | 比 | 判定 |
|---|---|---|---|---|
| 750日 | 58pp/年 | **96pp/年** | 0.60 | ノイズと区別できない |
| 2400日 | 20pp/年 | **43pp/年** | 0.47 | ノイズと区別できない |

**過去リターンの順位は、丸ごとノイズと整合する。** これを警告として出す。
併せて「Δμ=5pp を識別するのに必要な年数」（中央値σ使用）を絶対値の主張として保持
（実測 156〜201年 ＝ §3.2 の 144年 と整合）。

## 8d. P2 実装記録（2026-07-31 完了）── 持続性・順位安定性・構造変化・非対称性

### 8d.1 実体

`app/lib/sector-factor-stability.ts`（計算層）／`sector-factor-stability.worker.ts`（supWald のみ）／

### 8d.2 【重要】P1 の申し送りは実測で覆った

P1 は「b̂ の律速は統計誤差ではなく**時変性**」と結論し、§10 の原論追記にもそう書いた。
P2 の実測はその逆だった。

```
π(1年) = 0.97 [0.81, 1.03]     ヌル95% = 0.06      ← 順位はほぼ恒久的
上位5本の1年後生存 = 84%        完全ランダム = 36%
rankIC(S) = 0.84（1年）/ 0.80（2年）
半減期 2170日（標本長 2400日にほぼ等しい＝観測範囲で減衰が見えない）
```

一方で supWald は構造変化を検出した（8/14 銘柄が q<0.1、分割点は 2020-02〜2021-12 に集中）。
**この2つは矛盾しない。** 検出された変化は共通成分だったから（等加重バスケット自体に
p=0.017 の分割点、b 0.57→0.79、有意10本中9本が同符号）。**全員の身長が伸びても背の順は変わらない。**

帰結は非対称になる。

| | 影響 |
|---|---|
| **選別（相対）** | **無傷**。P1 の S 順位はチルトの根拠に使ってよい |
| **建玉サイズ（b の絶対値）** | **窓依存**。10年窓の b は「別レジームの平均」。露出を b で正規化するなら 2021-09 以降に切る |

二段収縮の効果はほぼゼロだった（ウェイト総変動 1.1%）。π が高いので当然で、
**この層の価値は「ウェイトを動かしたこと」ではなく「動かさなくてよいと確認したこと」**にある。

留保: 横断の散らばりの大半は構造的に別物の銘柄（セブン銀行 b=0.23・あおぞら 0.39 vs メガ 0.9）が
作っており、遷移行列の中間2分位（対角 0.37/0.57）は実際に入れ替わる。
**「上位5本を選ぶ」には十分安定だが、メガバンク3行の中の順位は動く。**

### 8d.3 §10（原論追記）の該当箇所の訂正

本書 §10 末尾の「b̂ の律速は統計誤差ではなく時変性に移る」は、**銀行セクターについては誤り**。

1. **m（金利観）の当否** ── 選別は増幅器であって創出器ではないという元々の主張がそのまま残る
2. **市場β 1.27** ── 採用5本の実態は「1.27倍レバレッジの日本株＋銀行ファクター」

の2つ。`app/lib/axioms/corollaries.ts` の C29 `derivation` には実測値つきで追記済み。

## 10. 原論への追記案 ─ 系C29

`docs/investment-axioms.md` 第5部の表に追加し、C26 の直後に置く。

| 系 | 既存理論 | 立脚する公準/命題 | 測る P の性質 → 変える q の選択 | 実装 |
|---|---|---|---|---|
| C29 | セクター内選別（ファクター感応度の識別可能性） | 公準4＋公準3＋命題4＋公理5／C24・C25・C26 の後段 | SE(b̂)=σ_ε/(σ_F√T) は頻度で縮む → **セクター内の銘柄間配分 w ∝ b/σ_ε² と本数 k** | SectorFactorSelectChart |

補足文（表の下に置く注釈）:

> **C29 は C26 の不可能性に対する唯一の抜け道を形式化する。** C26 は μ̂ の SE が観測頻度で縮まないこと
> （両端2点の恒等式）から個別ドリフトの識別を否定した。しかし回帰係数 b̂ の SE は
> `σ_ε/(σ_F√T)` であり、**毎日の観測が情報として入るため頻度で縮む**。σ が測れて μ が測れないのと
> 同じ非対称性が、b と μ の間にも成り立つ。ゆえに「どの銘柄が上がるか」は選べないが、
> 「どの銘柄がファクターに強く連動するか」は選べる。ただしこれは**エッジの創出ではなく増幅**であり、
> 期待値の源泉は投資家が外から持ち込む見立て `E[F]=m>0` にある（命題4: 情報の価値）。
> 選別が有効なのは m の符号が正しいときだけで、誤れば同じ倍率で損失も増幅される。
> 最大シャープ解は1ファクター模型下で `w ∝ b/σ_ε²`（Sherman–Morrison）に閉じ、
> **ファクター露出を保ったまま固有分散だけを分散できる**（k=5 で σ −9.4%・g* +2.7pp）。
> ゆえに C29 の実務的帰結は「セクターに集中し、セクター内では分散する」であり、
> 一点集中は C21（時間分散 vs 時間集中）と同じ理由で成長率を毀損する。
> b̂ の律速は統計誤差ではなく**時変性**に移るため、判定は前向きの順位相関（rankIC）と
> 床（等加重）に対する WF 超過で行う。**床に勝てないという結論が既定**である。
