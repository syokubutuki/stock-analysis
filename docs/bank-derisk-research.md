# 銀行株の下落局面で建玉を縮小する方法の探索（デリスク研究）

作成日: 2026-10-20 ／ コード: `research/bank-derisk/`（Python + 取得用 tsx）

## 0. 結論（先に）

- **「方向」は当てられない。「状態（荒れているか）」は当てられる。** 翌日の方向、5日先の急落（-4%超）は、
  線形回帰・ロジスティック・LightGBM・アンサンブルのどれでも、長期の時間外検証（OOS 2012〜2026）で予測力がほぼゼロ
  （日次IC -0.03〜+0.04、急落AUC 0.47〜0.60）。一方、**5日先の分散はMLが素朴な直近ボラより一貫して当たる**（QLIKE 0.56 対 0.64、3銘柄すべて）。
- **有効だったのは、複数のストレス指標を組み合わせ、ヒステリシス（戻りの遅い復帰）を付けた現金退避ルール**（§4）。
  - 最大DD: 買い持ち -83% → **-34%**（2006-09〜2026-10、3メガバンク平均）。年率は 5.8% → 10.4%、シャープ 0.17 → 0.48。
  - 4つの時代（リーマン、2010-12、2013-17、2018-26）すべてで最大DDが -50〜-79% → -25〜-34% に低下。
  - 同じ現金期間の長さ・本数をランダムに置いた偶然との比較で P<0.001（偶然ならDD中央値 -71%）。
  - 回転が年3回程度のため、片道20bpのコストでも結論は変わらない。
- **ただし「保険」であって「リターンの上積み」とは言えない。**
  年率の差はブートストラップ90%区間が [-4.5pt, +13.4pt] で0をまたぐ。強い上昇相場（2018〜26）では年率 22.6% → 16.5% と劣後する。
  また、**V字型の急落（2024年8月、2026年3月）では買い持ちより悪化した**（§6）。
- **1日単位の速い売買（前夜米国の動きで毎日建玉を変える）の優位は、頑健でなかった。**
  2020年以降だけを見ると α +13%/年（t=2.3）に見えたが、2012年以降に延ばすと消え（α -1%、t=-0.3）、片道10bpで半減、20bpで消える。
  効果の符号も年代で変わる（2008〜09年は逆符号）。**採用しない。**

## 1. 前提と確認事項（依頼文が途中で切れていた）

依頼文が「…判断を行う毎日の朝7時までに分かっている情報から当日のopenか」で途切れていたため、次の前提で進めた。
**違っていれば教えてほしい**（特に③）。

| # | 前提 |
|---|---|
| ① | 判断は毎営業日の朝7時（JST）。その時点で既知の情報だけを使う。 |

| ④ | 対象はメガバンク3行（8306.T 三菱UFJ、8316.T 三井住友FG、8411.T みずほ）の等ウェイト。1615.T（銀行ETF）は日商が薄い（直近15億円/日）ので参考のみ。 |
| ⑤ | コストは片道5bp（感度として0/10/20bp）。税・配当の再投資は調整後終値に含まれる。 |

### 7時時点で既知の情報（先読み防止）

- 日本側: **前営業日までの確定値**（終値・始値）。当日の始値は未確定なので使わない。
- 米国・VIX・金利・為替: 「日付が当日より厳密に小さい最新の行」（asof）。米国の終値は日本時間の翌朝5〜6時に確定する。
- 実装: `research/bank-derisk/common.py`（`asof_us`、すべての日本側特徴量に `shift(1)`）。

## 3. 検証の経過（何度も検証を重ねた記録）

| ラウンド | 内容 | 結果 |
|---|---|---|
| R0 診断 | 60特徴量と翌日リターンの順位相関 | 方向IC はほぼ全て|0.05|未満。**大きさ**（ボラ・VIX）はIC 0.15〜0.19で予測可能。唯一安定した方向の関係は「前夜米国高→日中反落」（4銘柄・10年中9年で負）。 |
| R1 単純ルール | SMA、直近高値からのDD、ボラ目標、VIX、米国前夜 | **SMA/DDで切るのは逆効果**（年率が大きく落ち、最大DDは改善せず）。銀行株は下げの後に戻りやすい。VIX急騰・米国前夜ルールは有望に見えた（全期間で選んだ値なので割引）。 |
| R2 ML | ridge/logit/LightGBM回帰・分類、アンサンブル。毎四半期再学習。OOS 2020〜 | IC +0.05〜0.13。一部でシャープ上昇（0.85→1.0〜1.3）、α t≈1〜2。**最大DDは改善せず**。3月2026の下落では建玉100%のまま。 |
| R3 ケリー型 | μ̂/(λσ̂²) の連続建玉 | OOS 2020〜でα +11〜17%、t 1.6〜2.6。回転が年約100回。 |
| R4 アブレーション | 特徴量群を外す | 米国を外しても同等。優位の中身は日本側の状態。コスト10bpでα+8%、20bpでゼロ。年別では2024・25年が大半。 |
| R5 回転抑制 | 不感帯・離散化・EMA平滑 | **平滑化すると優位が消える**＝1日単位の速い信号で、コストに脆い。 |

（グリッドでは3・5・8・12で同様の効果が出ており、尖った点ではない）。

## 4. 最終ルール（stress-hyst）

**毎営業日の朝7時に4つの指標を数え、2つ以上が点灯したらその日の寄りから全額現金。全指標が5営業日連続で消灯したら復帰。**

| # | 指標 | 点灯条件 | 7時時点の入力 |
|---|---|---|---|
| 1 | VIXの急騰 | VIX終値 ÷ 直近20日平均 > 1.25 | 直近の米国終値 |
| 2 | 対象銘柄のボラ拡大 | 5日実現ボラ ÷ 60日実現ボラ > 1.8 | 前営業日までの終値 |
| 3 | 対象銘柄の下落 | 直近60日高値からの下落 < -12% | 前営業日までの終値 |
| 4 | 米国地銀の下落 | KRE の直近60日高値からの下落 < -12% | 直近の米国終値 |

- 現金中は復帰条件のカウントだけ進める（1つでも点灯したらカウントをリセット）。
- 実装: `research/bank-derisk/r13_variants.py` の `stv()` と `hyst(k_in=2, calm_n=5, k_out=0)`。
- 設計の考え方: 方向を当てるのではなく、**荒れている間は平均リターンが期待を下回るのにボラが巨大**という状態を避ける。
  現金だった日の年率平均リターンは時代によって -43%〜+34%と符号が揺れ、年率ボラは27〜54%と大きい（`r7_slow.py` の `stress-hyst` 行。calm_n=3 の版）。
  つまり「その状態が将来の下落を予告する」のではなく、「荒れた状態の間は損益の振れが巨大になる」ことを避けている面が強い。
- 現在（データ最終日 2026-10-16）: 3行とも 0/4 点灯で保有。ただし dd60 が -8〜-11%、KRE が -10% で閾値（-12%）に近い。

## 6. 局面別（3メガバンク平均）— 効かなかった局面も含む

| 局面 | 買い持ち 期間累積（窓内最大DD） | ルール 期間累積（窓内最大DD） | 現金日 |
|---|---|---|---|
| リーマン危機 2007-07〜2009-03 | -70.5%（-76.4%） | -3.2%（-10.5%） | 90% |
| 東日本大震災 2011-03〜06 | -16.4%（-25.1%） | -15.4%（-18.7%） | 84% |
| 中国・マイナス金利 2015-06〜2016-07 | -38.7%（-50.0%） | -28.2%（-32.9%） | 55% |
| 2018年 | -30.0%（-32.1%） | -15.6%（-21.0%） | 40% |
| コロナ 2020-02〜04 | -22.5%（-31.8%） | -5.4%（-5.3%） | 86% |
| **2024年8月** | -14.9%（-29.0%） | **-25.7%**（-27.4%） | 64% |
| 2025年4月 | -9.6%（-37.9%） | +0.0%（0.0%） | 100% |
| **2026年3月** | -6.2%（-14.6%） | **-14.1%**（-13.4%） | 58% |

**読み方**: 下落が数週間〜数カ月続く局面（リーマン、2015〜16、2018、コロナ、2025年4月）では大きく守る。
一方、**1日で急落してすぐ戻る局面（2024年8月5日の-20%超、2026年3月の乱高下）では、急落の後に退避して戻りを逃し、買い持ちより悪化する**。
指標は前日までの確定値なので、1日で終わる急落そのものは避けられない。「最近の銀行下落」が後者の型なら、このルールは効きにくい。

## 7. 採用しなかったもの（再検討しないための記録）

- **トレンド・DD単独ルール**（SMA50/200、60日高値から-8%など）: 年率の低下が大きく最大DDは改善しない。
- **前夜米国の動きによる毎日の建玉変更**（ギャップ反転）: 時代・銘柄で効果が変わり（2008〜09年は逆符号）、コストに脆い。
- **急落確率のMLで建玉を絞る**: AUC≈0.5。2020年OOSでは学習に危機が無く、2006年以降を学習させても改善しなかった。
- **ケリー型の連続建玉**: 長期OOSでは買い持ちに劣後（年率 6.7% 対 20.8%）。μ̂ の信頼性が低く、低ボラ時以外に推定誤差が効く。
- **ボラ目標のみ**: ボラ予測は精度が上がるが、危機の入口ではボラが上がり切る前に下落が進むため最大DDは下がらない。
- **段階的な縮小**（0.25〜0.5刻み）: 全変種が全額退避に劣後。
- **V字型の急落への対策**（20日DD指標、速い指標だけでの復帰、復帰日数の短縮）: 7変種すべて失敗（R16）。
  V字の損失は「急落が1日で起きる」ことと「指標が前日までの確定値」であることから来るため、復帰条件の調整では直らない。
  この型への備えは、このルールの外（先物・オプションでのヘッジ、建玉サイズの事前制限）で考える必要がある。

## 8. 限界と注意

- 評価は3メガバンクの等ウェイト。3行の相関は高く、独立な標本ではない。
- 設計の多くを2018年以降のデータを見て決めた。2018年以前（2006〜2017）は時間外の検証にあたるが、最終ルールの定義（`calm_n=5`、k_in=2）の微調整は全期間を見たうえで行った。
- 配当・分割は調整後終値に含まれる（再投資扱い）。税、信用取引の金利、現金の運用益は未考慮。
- 約定は始値の仮定。実際は寄り付きの成行・OCO等で滑る。メガバンク3行は流動性が高いが、1615.T は薄い。
- 2024年8月型の急落に対する対策は未解決。復帰を早める変種は全期間で効果が落ちる（R13・R16）。
- このコードは分析用の研究であり、アプリへの組み込みは行っていない。投資助言ではない。
