## 見落とされている問題（重要度順）

### ① 289コンポーネント分の解説が、SEO資産として1文字も使われていない

```
AnalysisGuide を持つコンポーネント: 289
/guide として公開されているページ:   8
sitemap.xml の URL 総数:            13
```

CLAUDE.md の規約で「①手法概要 ②数式（省略しない）③日本語定義 ④直感的な例え
⑤読み方 ⑥投資への活用 ⑦限界」を289コンポーネントに書かせてきた。
日本語で書かれた金融統計の解説として国内トップクラスの蓄積が、
クライアントバンドルの中で圧縮され、Googleに1文字も届いていない。

本番HTML実測:

```
https://kabugenron.com/          → HTML 14,647B / 可読テキスト ≒ 免責文のみ
https://kabugenron.com/portfolio → 可読テキスト 1,001文字（実質ゼロ）
https://kabugenron.com/strategy  → 可読テキスト   652文字（実質ゼロ）
https://kabugenron.com/axioms    → 可読テキスト 19,044文字（唯一の実コンテンツ）
```

シェル（ヘッダ・免責）はSSRされているが、`app/page.tsx:1` が `"use client"`、
全チャートが `ssr: false`、データはクライアント取得。
クローラが見る分析コンテンツは存在しない。

### ② og:image が無い ＝ 唯一の獲得経路が塞がっている

```
ogImage: "NONE"                 // 実測
twitter: { card: "summary" }    // app/layout.tsx:41 — 大画像ですらない
```

個人開発の分析ツールが伸びる経路は、検索よりまず「この図すごい」でXに貼られること。
貼られるための図を244枚持っているのに、共有すると無地のテキストカードになる。
`app/opengraph-image.tsx` は存在しない。

### ③ 前向き検証台帳が、最も失われやすい場所にある

`ProspectiveLedgerChart`（凍結→未来のデータだけで採点）は
時間が経つほど価値が増える唯一の資産。3ヶ月分の凍結記録は他のどのサイトにも複製できない。

それが localStorage にある。ブラウザを変えたら消える。
乗り換えコストが生まれる唯一の場所を、揮発性ストレージに置いている。
（移行設計は `docs/prospective-ledger-server.md` に既存・未実装）

### ④「すべて開く」が銘柄をまたいで永続する地雷

`CollapsibleAnalysis.tsx:24` の `sa:open:<id>` は銘柄非依存で永続する。
設計意図（再検索しても開いている分析集合を維持）は正しいが、
`AccordionSection.tsx:59` の「すべて開く」を一度押すと、
以後すべての銘柄で56パネルが同時マウント・同時計算される。

実測でカレンダー節のパネルを1枚開いたとき、レンダラが応答不能になり
CDPスクリーンショットが30秒タイムアウトした（再取得で復帰）。
1回の観測なので断定はしないが、56枚同時が何を起こすかは想像がつく。

### ⑤ 数値の桁が揃っていない

本番実測:

```
現在値 2,914.5      期間始値 3,452.592
現在値 3,541        期間始値 2,751.819
```

`app/page.tsx:1477-1481` が `close.toLocaleString()` を素通ししているため。
配当調整済み終値なので小数が出るのは正しいが、
数字を売っている製品で桁が揃っていないのは、精度への疑いを最初の3秒で植え付ける。
価格破損の修復にあれだけ投資しているサイトが、表示で信頼を落としている。

### ⑥ 24タブが「提供者の分類」になっている

`量子力学的` `非線形動力学` `情報理論` `フラクタル` は手法の分類であって
ユーザーの質問の分類ではない。ユーザーが持ってくる問いは3つ:

- 今買っていいか
- どれくらい下がりうるか
- この傾向は本物か

この3つに1タブも割かれていない。
`条件付き分析` `エッジ探索` `as-of検証` が実質それに当たるのに、名前がそう読めない。

### ⑦ 使えないコントロールが一等地を占めている

`page.tsx:1396`。`入力系列` セレクタ6個が全部グレーアウトし
「（このセクションには適用されません）」と表示される。
ファーストビューの縦2行を、押せないボタンが消費している。

### ⑧ 最初のパネルが「価格データの破損点検」

`page.tsx:1458`。保守者の関心であって来訪者の最初の関心ではない。
データ品質への誠実さは強みだが、置き場所が最前列である必要はない。

### ⑨ 上下の色が日本の証券アプリと逆

緑=上昇 / 赤=下落（米国式）。SBI・楽天・松井はすべて赤=上昇 / 青=下落。
日本の個人投資家は反射で読み違える。
国際的・クオンツ的には現状が正しいので、意識して決めるべき論点。設定切替が最善。

### ⑩ 日本語フォントが指定されていない

```css
/* app/globals.css:16 */
font-family: Arial, Helvetica, sans-serif;
```

日本語が1文字も入っていない。ブラウザ既定にフォールバックし、
Windows/Mac/Androidで別物になる。`next/font` も未使用。

値付けの構造的な問題:

> Pro の訴求＝「全244パネル」「期間10年」

誰も「統計が増えること」には払わない。

「使い切れないものが、もっと増える」としか読めない。

払うのは次のどれか:

1. **時間が節約される** —「56枚開かなくても、今日見るべき3枚が分かる」
2. **判断が記録される** — 前向き検証台帳がサーバーに永続し、半年後に自分の判断精度が分かる
3. **失敗が減る** — 「そのエッジは偶然です」と止めてくれる

は残すこと。これ自体が最高のブランドメッセージであり、
そのまま価格ページの一等地に置くべき文章。

### ユーザー心理

トップのコピーは「市場の隠れた構造をデータから抽出する」。
これはあなたが何をするかであって、訪問者が何を得るかではない。

そして最初に読ませているのが、免責・警告・
「有意でも標本期間でそう見えただけ」という自己批判。
誠実さは本物だが、初訪問者の3秒で伝わるのは「難しそう」「自分向けではない」。

さらに初訪問者は全員トヨタ（`DEFAULT_TICKER = "7203.T"`）を見せられる。
当事者性ゼロの状態で56枚の壁に当たる。

| 改善案 | 優先度 | 効果 | コスト |
|---|---|---|---|
| ヒーローを「あなたの銘柄の、その傾向が偶然かどうかを判定します」に | S | 大 | 極小 |
| 免責は残しつつ位置を下げる（法的には十分機能する） | A | 中 | 極小 |
| 初訪問時に銘柄入力を最初の唯一のアクションにする | A | 大 | 小 |

## 結論

このサイトの本当の価値は244枚のチャートではない。
**「その傾向は偶然です」と言い切れること** である。

ヌル較正で「エッジゼロでも+279%出る」ことを実証し、
`weekday-barrier` を「全層null」と記録し、
`timing-value-spa` を「p=0.334で裏付けなし」と書いて残している。
そして `tiers.ts` に「毒を配って解毒剤を売る構造は原則と衝突する」と明記して
検証ツールを無料側に固定している。

株式分析サイトで、否定を売り物にできるサイトは他にない。
世の中の全部が「見つかりました」しか言わない中で、
このサイトだけが「見つかりませんでした」と言える。

トップに書くべきは「市場の隠れた構造を抽出する」ではなく、
**「その傾向が偶然かどうか、判定します」**。
